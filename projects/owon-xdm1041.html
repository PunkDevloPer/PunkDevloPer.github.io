OWON XDM1041 Controller

Python · SCPI · REST API · Instrumentación

Descripción

Proyecto para controlar y automatizar un multímetro OWON XDM1041 desde Linux. La base técnica se centra en comunicación SCPI, adquisición de medidas y una arquitectura que permita añadir GUI y API REST sin acoplarlas al transporte del instrumento.

Objetivos

  • Comunicación fiable con el instrumento.
  • API interna limpia para medidas y configuración.
  • Registro y exportación de datos.
  • Interfaz gráfica desacoplada del controlador.
  • API REST para integraciones y automatización.
